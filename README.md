   # QA Python Automation [![Tests](https://github.com/Amferot0/qa_python_automation/actions/workflows/tests.yml/badge.svg)](https://github.com/Amferot0/qa_python_automation/actions/workflows/tests.yml)
   📊 [Allure report](https://amferot0.github.io/qa_python_automation/)

   Учебный проект: путь от ручного QA к автоматизации на Python.

   ## Структура
   - `tests/` — API-тесты (pytest + requests)
   - `lessons/` — учебные скрипты по Python
   - `tests/conftest.py` — общие фикстуры

   ## Запуск
   pip install requests pytest
   python -m pytest -v
